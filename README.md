# Musigram

[English](#english) · [Русский](#русский)

## English

An unofficial Telegram client for Android built around music. Sign in with your
Telegram account and turn your channels, chats and bots into a music library.

- **Wave**: an endless stream of recommendations tuned to your taste
- **Search**: find tracks and artists
- **Library**: tracks downloaded from Telegram channels, chats and bots
- **Sources**: choose which chats to collect music from
- Background playback and Android Auto support

### Download

Get the latest version from **[Releases](../../releases/latest)** (the `musigram-*.apk` file).
Short link: https://musigram-app.ru/download

### Install

1. Download the APK to your phone.
2. Open it and allow installs from this source if Android asks.
3. Sign in with your Telegram account.

New versions install over old ones, and your data is kept.

### Beta

This is a public beta, and new builds come out regularly. Keep an eye on
updates and install the latest version from Releases. To get notified, click
**Watch → Custom → Releases** at the top of this page.

### Feedback

Report bugs and send suggestions in [Issues](../../issues).

Musigram is an unofficial app. It is not affiliated with, endorsed by, or
sponsored by Telegram. It uses the Telegram API to access your account.

The source code is closed. This repository only hosts builds.

## Русский

Неофициальный Telegram-клиент для Android, созданный для музыки. Войдите
в свой аккаунт Telegram, и ваши каналы, чаты и боты станут музыкальной медиатекой.

- **Волна**: бесконечный поток рекомендаций под ваш вкус
- **Поиск**: поиск треков и исполнителей
- **Медиа**: треки, скачанные из Telegram-каналов, чатов и ботов
- **Источники**: выбирайте, из каких чатов собирать музыку
- Фоновое воспроизведение и поддержка Android Auto

Последняя версия лежит в **[Releases](../../releases/latest)** (файл `musigram-*.apk`).
